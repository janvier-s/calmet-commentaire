# How Calmet's abbreviations are written out in the footnotes (footnotes.py gives this to Claude).
# "abbreviation = French". Context decides between two readings (marked "or").

## Words
l. / lib. / Lib. = livre        c. / cap. / Cap. / ch. / chap. = chapitre       n. = numéro
hom. / homil. = homélie         ep. / epist. = lettre       serm. = sermon      orat. = discours
q. / qu. / quæst. / quaest. = question       tract. = traité       art. = article
p. / pag. = page                edit. / Edit. = édition      not. = note        col. = colonne
v. (in a poem) = vers            ℣. = verset                 init. = au commencement
apud X = dans X                  ex X = d'après X             vide / vid. / voi = voyez
ibid. = au même endroit (or: the reference before it, written out)   id. / idem = le même
hic / in loc. / in hunc locum = sur ce passage       et alii / alii = et d'autres     passim = passim
seq. / sequ. / sq. = et suivants        etc. = etc.        Ms. / Mss. = manuscrit(s)
